# UFC-Data-Analysis
Analyzing UFC fights from 1993 to 2021. "FightAnalysis.ipynb" is my first attempt at analyzing the dataset, which wasn't very successful. Read "Main.ipynb" for the actual UFC data analysis. Attempts to answer the question of what fighting aspects are significantly different between fighters who have won title fights and fighters who haven't.


**Skills Used:**
* Python
* Pandas
* Numpy
* Matplotlib (Heatmap, Histogram, Boxplot)
* Statsmodels (QQ-Plot)
* Scipy (Shapiro Wilk Test, Levene Test, Bootstrap)


**Link to Data:** https://www.kaggle.com/datasets/rajeevw/ufcdata
